為什麼我覺得 OpenAI 可能才是目前 AI 模型供應商的領先者，而非 Anthropic？

從算力供給、應用競爭與資源重新配置，思考 AI 模型供應商的優勢。

AI 產業 / 算力 / 商業模式

（Note：關於算力儲備的觀點最早是受到《美投講美股》啟發，我於這篇補充許多延伸觀點與判斷。想看大方向介紹的可以直接看《AI产业已秘密转向！趁市场未动，这3大机会抓紧布局！》這集）

先前市場一直擔心的 AI 變現問題，Anthropic 看起來已經幫大家走通了。尤其是 Claude Code 的成功，基本上證明了短期 B-side 的商業模式是成立的：AI 可以直接進入個人工作流，變成企業願意付高價的生產力基礎設施。

因此市場似乎看起來更看好 Anthropic，Anthropic 目前的估值高於 OpenAI 的。但我覺得市場可能把這件事解讀得太單線了。

Claude Code 比較早驗證 B-side 變現通道，不代表 Anthropic 能長期壟斷這塊市場。我的想法是：在模型與應用差距尚未被拉開、企業端前沿模型需求仍供不應求的階段，真正重要的變數可能不是誰先做出某個產品，而是誰有更多可調度算力、較低算力成本，以及更大的算力重新配置空間。

換句話說，OpenAI 當初非常激進地 secure 算力，現在回頭看不一定是過度投資，反而可能是押中了 AI 商業化後真正的瓶頸。

（目前我沒有很精確的數字去確定究竟兩家公司的鎖定的算力差距究竟是多少，一些來源的推估是五年內大約是 26GW vs 11GW，但大方向上 OpenAI 鎖定的算力規模比較大是沒什麼問題的。）

【模型層：現有範式下，價值成本比很難拉出決定性差距】

今天模型不需要再有巨大的性能飛躍，也足以支撐非常多高價值工作流。接下來除非某家公司能帶來非常明顯的「價值成本比」的增長，否則單純模型能力的微幅進步很難轉化為定價能力。

而且從過去我們看到這些 AI Lab 交替領先好幾輪了，我覺得模型層即使出現技術差距（例如某模型明顯的更 efficient），也可能會在短時間內被追上。

當然，這個判斷建立在一個前提上：短期內沒有某家公司突然走出完全不同的新範式。目前看起來，預訓練、後訓練、推理量這幾條成長曲線都還沒有被榨乾。從一些 AI 大佬的訪談來看，關鍵似乎仍然很大程度落在 infra、資料等細節的執行力上。

【應用層：Coding agent 的功能領先窗口非常短】

應用層我覺得比模型層更難形成長期差距。

AI 應用如果有獨特資料，確實可能建立護城河。像 Bloomberg 有金融資料，Meta 有社群資料，Google 有搜尋與廣告資料，可能可以做出一些獨特的應用。

但當我們單獨討論已經商模跑通的 Coding Agent，如果只是純功能面的產品創新，領先窗口正在快速變短。

原因自然是 AI 本身的實作能力已經太強了，尤其 AI Lab 在 AI 輔助開發上一定是做到最極致的。

好的 idea 和好的執行力仍然重要，但它們能帶來的時間優勢正在縮短：幾個月前 Claude Code 很早推出 Hook、Remote Control 等功能，在使用者體驗與效率上取得明顯領先。（很長一段時間我都只好自己在 Codex 上用開源的方法搞 Remote Control）

但現在 OpenAI Codex 也很快補上了很多必要功能，甚至在 AppShots、Chrome Extension 等方向上更早推出。

這也代表除非背後有獨特資料、enterprise relationship，否則單靠功能本身很難形成長期護城河。

所以我不太認為 Anthropic 的優勢是所謂「客戶黏性」。它當然有先發優勢，但這種黏性不像 ERP 那類的那麼強。Coding agent 的切換成本相對低，只要另一邊模型能力接近、價格更低、quota 更多，使用者和企業大多可以轉移。

【算力層：AI 不是傳統 SaaS，邊際成本與 capacity 很重要】

AI 應用跟傳統軟體最大的不同，是它有高邊際推論成本：使用者每多跑一次 agent，都會真實消耗算力。

而且推論算力不只是成本，也會影響任務完成品質。對 coding agent 這類產品來說，同一個工程師使用同一個模型，能使用多少推論資源，大體上就會影響他能提升多少實際生產力。

所以在需求供不應求時，可用算力某種程度上就是模型供應商的營收 capacity。

這也讓「客戶黏性」的重要性下降。黏性只有在你有能力服務客戶時才有價值。如果客戶願意買更多 token、更高 quota、更強模型，但你沒有 capacity，那收入就會被硬體上限卡住。

Anthropic 未來當然可以追加採購算力，但未必能以同樣條件取得。因為目前瓶頸從晶片、HBM 到電力等等。越晚 secure 的 capacity，通常會面臨更高的不確定性、更長交付期，以及更高的機會成本。

而且，在算力稀缺的市場裡，可服務需求 = 模型能力 x 算力。

模型能力決定每單位算力能創造多少價值；可用算力決定你實際能服務多少需求；算力成本則決定毛利與價格戰承受力。

所以即使 Anthropic 真的能做出明顯更強的模型，它要超越 OpenAI，也不只是模型要更好，而是模型能力的差距必須大到足以抵消 OpenAI 在可用算力、供給穩定性與成本上的優勢。

【OpenAI 的優勢：更大的算力 reallocation option】

OpenAI 現在同時具備三個條件：

  1. secure 的算力規模更大。
  2. 有更廣的產品與客戶需求組合。
  3. 目前不同 workload 之間可能存在明顯 ROI 差距。

這三件事構成 OpenAI 的算力 reallocation option value。

比較早之前，OpenAI 停掉 Sora，並且有消息說會把更多資源轉向 Codex。我覺得這件事就蠻有代表性的，這表示 OpenAI 正在收縮短期變現效率較低的產品線，把資源轉向更高 ROI 的工作流。

這就是我覺得 OpenAI 真正優勢的地方。

OpenAI 不只是算力比較多。更重要的是，它有算力配置的選擇權。它可以選擇砍掉或降低某些低 ROI 的 C side 產品，把算力轉去更高 ROI 的 B side，甚至近期 OpenAI 已經開始在賣 guaranteed capacity。這種可重分配算力的價值，我覺得市場可能沒有充分反映。

換個角度看，市場上很多人批評 OpenAI 產品線混亂、C-side 用戶多但付費比例低。這確實是一個風險，但它也可以是一種對「AI 應用創新風險」的對沖。萬一未來又有某個 C-side 應用被驗證，OpenAI 有更多產品與既有用戶可以快速調整算力分布，讓算力流向 ROI 更高的地方。

【OpenAI 的優勢是否是可持續的？】

不過，OpenAI 的 compute reallocation option 也許不是永久護城河。這件事成立的節點只有在算力仍然稀缺、模型與應用差距沒有被拉開的階段。

長期來看，未來這些供應商「可能」沒有非要把算力提供給 OpenAI 的理由，再加上算力供給擴張、模型效率提升，今天的 capacity premium 未必會永久存在。

但短期來看，這個優勢仍然重要。因為它可能帶來正向回饋：更多算力帶來更多可服務需求，更多需求帶來更多收入，更多收入又能支撐更大規模的算力投資。

【結語：Anthropic 可能替 OpenAI 驗證了市場】

總結而言，Claude Code 的成功不一定是 Anthropic 的終局優勢。它也可能是替 OpenAI 驗證了市場。

當然這一切假設都建立在供不應求，但以資本開支還在持續成長的前提之下，我認為這個假設在短期內還是很成立的，萬一真的不成立的話 OpenAI 的算力優勢就變成是一種高槓桿風險。

我也覺得多數企業的採用實際上是比預想中緩慢的，成長可能還可以持續好一段時間。近期有看到有些大公司說要開始檢討 AI 模型的 ROI，我覺得也不是什麼壞信號，這本來就是發展的必然歷程，只是大家還沒有找到一個明確的範式去最大化 ROI 而已。

在這些假設下，誰有更多可調度算力，誰就能服務更多需求，誰就能在價格戰裡活得更久，也更有機會把 B side 變現的成果吃下來。

結論是我現在比較傾向市場可能高估了 Anthropic 先發優勢的持久性，也低估了 OpenAI 在算力層和資源重新配置上的優勢。

（不過我也不是搞金融的，只是上面這個論點我覺得跟我自己的理解、使用體驗相符，所以分享出來的一些淺薄觀點而已；且很多很強的假設隨時會失效，商業、應用、技術也都完全可能出現意想不到的新範式，所以參考就好～）
